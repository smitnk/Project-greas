# 6. NATIVE ARCHITECTURE DECISION

The chosen route is ROUTE A: minimal Android GPU backend.

Target:
Blender GP geometry/cache
 -> GPUVertFormat / GPUVertBuf / GPUIndexBuf / GPUBatch
 -> minimal Android GPU backend
 -> GLES VBO/IBO/VAO + focused GP shader/presentation
 -> Android EGL surface

Avoid:
- Blender stock desktop GLBackend
- full GPUContext dependency closure
- full GLContext/Framebuffer/Texture/Shader/StorageBuf/Query/Compute
- full DRW
- full desktop GPENCIL engine
- VFX/SMAA/masking/full material system
- full scene/Main/ID/depsgraph/RNA architecture

The Android app owns the graphics context.
